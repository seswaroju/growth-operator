# Format:  <path-substring>::<token>   # justification (REQUIRED)
#   A violation is excused when <path-substring> appears in the file path AND
#   <token> appears in the flagged line. Every entry MUST carry a '# justification'
#   comment — an entry without one FAILS the guards (guards.py load_allowlist).
#
# Example (kept commented; real entries go below, uncommented):
#   core/insights/example.py::restaurant   # string appears in a doc URL, not industry logic
#
tests/unit/test_lint_guards.py::approval_policies   # justification: the guard's own red-path fixtures. These strings are written into a tmp directory to prove test-policy-writes fires; this file opens no database connection. Narrowly scoped to this one file so a real unscoped write anywhere else in tests/ is still caught.
